# niri keybindings

`Mod` is niri's compositor modifier (normally Super/Windows).

| Shortcut | Action |
| --- | --- |
| Mod + Return | Kitty |
| Mod + D | Fuzzel launcher |
| Mod + P | Select screenshot region and copy to clipboard |
| Mod + Q | Close window |
| Mod + O | Toggle overview |
| Mod + Left/Right | Focus adjacent column |
| Mod + Up/Down | Focus window |
| Mod + F | Fullscreen |
| Mod + Shift + Left/Right | Move column |
| Mod + Escape | Quit niri |

Startup launches Kitty, Noctalia, and the KDE polkit authentication agent. Steam's main window opens at full column width; Steam game windows open fullscreen.

Use `dots-backup` after editing live bindings, or edit the repository and run `dots-restore`. Run `niri validate` before experimenting with a live config.
