# Third-party appearance assets

- The initial background is the user's selected image from [Wallhaven 6d21v7](https://wallhaven.cc/w/6d21v7). It is included as a desktop asset, with rights retained by its original rights holders; it is not covered by a software license for this repository. A later `dots-backup` can replace it with the selected background, so update this attribution when changing the published image.
- The customized Kvantum config derives from [Catppuccin/Kvantum](https://github.com/catppuccin/Kvantum), under its MIT license. The base SVG/theme comes from the optional package, rather than being copied into this repo.
- The GTK theme is provided by [Catppuccin/GTK](https://github.com/catppuccin/gtk), GPL-3.0. The GTK stylesheet includes theme CSS and Noctalia-generated colors; backup captures the selected generated stylesheet.
- Generated colors/config snippets are produced by [Noctalia](https://github.com/noctalia-dev/noctalia). The chosen shell palette is Catppuccin Mocha Mauve-Lavender.

Upstream theme licenses are retained under `licenses/` for configurations derived from those projects.
